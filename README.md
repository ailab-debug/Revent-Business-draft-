# Revent Business website draft

Functional landing-page prototype for Revent Business, including the workplace-equipment catalogue, rental calculator, cart, service options, FAQs, WhatsApp contact, and quote-request flow.

The site is automatically deployed to GitHub Pages whenever the `main` branch is updated.

## Structure

- `dist/index.html` - website, styles, and interactions
- `dist/assets/` - Revent logo and catalogue imagery

## Important

Pricing shown in the calculator is indicative. The quote form currently stores the submitted draft locally in the visitor's browser and is not connected to a CRM or email service.
